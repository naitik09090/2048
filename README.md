# 🎮 2048 Game - Modern Edition

A beautifully redesigned version of the classic 2048 puzzle game with stunning animations, glassmorphic design, and vibrant visual effects.

![2048 Game](https://img.shields.io/badge/Game-2048-brightgreen)
![React](https://img.shields.io/badge/React-18.x-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Features

- 🎨 **Modern UI Design** - Glassmorphic containers with animated gradient backgrounds
- 💫 **Smooth Animations** - Tile movements, spawns, and merges with CSS animations
- 🌈 **Vibrant Colors** - Each tile has unique gradient colors and glow effects
- ✨ **Special Effects** - Rotating borders, pulsing glows, and celebration animations
- 📱 **Responsive Design** - Works perfectly on desktop and mobile devices
- 🎯 **Original Gameplay** - Classic 2048 mechanics you know and love

## 🎬 Animations & Effects

### Tile Animations
- **Tile 2**: Rotating golden border with sparkle effects
- **Tile 4**: Pulsing radial overlay with coral glow
- **Tile 8**: Twinkling sparkle emoji with pink-magenta glow
- **Tile 16-64**: Progressive glow intensity animations
- **Tile 128-1024**: Enhanced glow effects with multiple colors
- **Tile 2048**: Rainbow rotating halo + celebration emoji 🎉

### UI Elements
- Animated gradient background that shifts colors
- Glassmorphic game container with blur effects
- Glowing title with pulsing animation
- Smooth tile spawn and merge animations
- Game over screen with fade-in effect

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/naitik09090/2048.git
cd 2048
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

4. Open your browser and navigate to `http://localhost:3000`

## 🎮 How to Play

- Use **arrow keys** (↑ ↓ ← →) to move tiles
- Tiles with the same number **merge** when they touch
- Create a tile with the number **2048** to win!
- Keep playing to achieve higher scores
